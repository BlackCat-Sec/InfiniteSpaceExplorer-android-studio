# Infinite Space Explorer Android Studio Repo

This repository is packaged so the repository root can be opened directly in Android Studio.

## Open In Android Studio

1. Clone the repository.
2. Open the repository root in Android Studio.
3. Let Gradle sync.
4. Run the `SpaceExplorerPort` configuration.

## Requirements

- Android SDK Platform 34
- Android NDK `28.2.13676358`
- Android Studio embedded JDK

## Output

The debug APK is generated at:

- `app/build/outputs/apk/debug/SpaceExplorerPort-debug.apk`
